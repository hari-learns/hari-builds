Guardian HCS Box Loader with Hydraulic Chute System

Price on request

The Guardian HCS Box Loader is the natural progression from the original Guardian Potato Box Loader by Larrington Trailers. While the concept came about while working on a system to handle cabbages, the system can actually handle multiple different crops with ease. Just like the original Guardian Box Loader the Cabbage and multi-crop Box Loader enables you to load from a harvester directly in to boxes.

Built to order in Boston, Lincolnshire. Price is given on request, as on larringtontrailers.com.

Soft Cushioned Top

The top of the trailer is covered in a thick layer of protective foam. Eliminating any excess damage usually caused when loading in a conventional trailer.

Patented Cushion Lock System

The Cabbage Box Loader features a new patented cushion lock system, which while built with cabbages in mind, was developped to handle a multitude of different crops. These cushion locks ensure the crops is distributed in a controlled and gentle way in to the boxes below.

Easy Unloading

Once the full length of the top is filled with potatoes, the box loader is taken back to the farm, where the top frame is lifted to fill the boxes. An electric hydraulic system in the tractor cab gives the driver full control of the speed at which the top lifts, and the of the loading of the boxes.
