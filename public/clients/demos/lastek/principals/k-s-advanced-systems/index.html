K&S Advanced Systems

Vibration Isolation Solutions

K&S Advanced Systems Ltd develop and manufacture systems that set the next-level industry standard of vibration isolation for precision instruments.

K&S Advanced System's goal to be a world-leader in the design and manufacture of high technologically innovative vibration isolation systems, solutions for vibration sensitive instruments, tools, and processes. Lastek is pleased to announce they have been appointed distributor for K&S advanced Systems Ltd in Australia and New Zealand.

Their products include:

  • SotoTT Table Top Passive Vibration Isolation System
  • ArisTT Table Top Active Vibration Isolation System
  • ArisMD Modular Active Vibration Isolation System
  • SotoMD Modular Passive Vibration Isolation System
  • Electron Microscopy Application Note
  • IVF Application Note
  • Semiconductors Application Note
  • Tabletop Devices Application Note
