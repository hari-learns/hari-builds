Sala

Projeto Restyling Sala

  • Residencial
  • Projeto 3D
  • Projeto académico
  • 4 imagens 3D

Projeto de interiores desenvolvido para o restyling de uma sala.

Dimensionamento e Organização Visual e Funcional do espaço interior existente.

A cliente pretendia um ambiente neutro, com algum apontamento de cor e a inclusão de alguns elementos naturais que iriam contrastar com a nobreza dos tons ouro.

Como aspeto importante a considerar neste espaço foi a gestão de circulação e acessos, uma vez que as diversas funções da mesma (Hall entrada, acesso a cozinha, acesso a IS, acesso a andar superior) retiram a devida privacidade a esta sala.

Projeto desenvolvido em âmbito académico.
