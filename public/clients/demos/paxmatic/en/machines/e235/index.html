E235

Friction feeder EasyFeeder

The universal friction feeder for flat products of all kinds.

Technical data

Performance range
max. 40 m/min; up to 60 cycles/min (A5, cycled)
Format range
min. 80 x 60 mm; max. 300 x 235 mm (short side leading)
Product passage
min. 0.1 mm; max. 5 mm, paper min. 80 g/m²
Supply
230 V / 50 Hz, 200 VA
Dimensions
684 x 336 x 320 mm, approx. 20 kg

Features

  • Dispensing width 235 mm, central air-gap adjustment from 0.1 to 5 mm
  • Modular, compact industrial machine concept

Options

  • Preset counter and daily counter
  • Start light barrier for external start pulse
  • Clock generator to set the cycle speed
  • Mobile base, height adjustable +/- 50 mm
  • Level control in stack magazine / feed belt
