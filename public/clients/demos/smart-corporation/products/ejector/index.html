Which sealer fits my container?

This is a product which can be used as an option in case SES-3400, SES-3400U product which is an Induction Sealer (Line type) among Smart Induction sealer. Induction sealer (Line type) is a product doing sealing when container with the state of closed cap is passing on the container. It detects whether liner is placed in a cap or not, and ejects if there is no liner in a cap.

Features

  • Standard product attached to SES-3400, SES-3400U
  • Attached directly to the body and it is designed to reduce the cost of support fixture
  • Use clean and lightweight aluminum and stainless steel
  • Attachment and detachment can be done easily and height is adjustable
  • Adjustable speed (speed adjustment: Min. ~ Max.25M / Min)
